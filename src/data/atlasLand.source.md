# Atlas coastlines

`atlasLand.json` contains rounded outer land rings from Natural Earth, 1:110m physical land, public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Coordinates are used to draw an illustrative, orthographic destination globe on the homepage. No remote map requests are made by visitors.
